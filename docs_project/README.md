# Nome Project Memory

This folder holds durable context for the Telegram personal-assistant bot.

## Index

- `project/product-brief.md`: product direction, users, and boundaries.
- `project/architecture.md`: implementation shape and integration boundaries.
- `project/devops/ai-pr-workflow.md`: PR and review workflow.
- `project/devops/review-contract.md`: review evidence expectations.

Use the active `specs/<feature-id>/` folder as the source of truth for current
work. Update these docs only when a decision should survive beyond one PR.
